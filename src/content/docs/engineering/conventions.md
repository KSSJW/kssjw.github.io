---
title: Conventions
description: Development standards and conventions used across FuseLeaf Studio projects.
---

FuseLeaf Studio follows a set of shared engineering conventions to keep our projects consistent, maintainable, and easy to contribute to.

### Conventional Commits

We use **Conventional Commits** to keep commit messages consistent and meaningful.

Commits should clearly describe the type and purpose of a change.

### Checkstyle

Java projects use **Checkstyle** to enforce consistent code style and maintain code quality.

Project-specific configurations may extend or modify the shared rules when necessary.

### Semantic Versioning

We use **Semantic Versioning (SemVer)** to communicate changes and maintain compatibility between releases.

Projects may define additional versioning rules when required by their ecosystem.

> **Consistent by convention, flexible by design.**
